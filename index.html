Data Structures Implementation

Core Data Structures implemented from scratch in C++

Project Overview

This project implements Singly Linked List, Doubly Linked List, Stack, and Queue in C++. Each structure supports insertion, deletion, searching, and traversal with proper memory management.

Implemented Data Structures

Singly Linked List

Nodes connected using a next pointer.

Doubly Linked List

Nodes connected using previous and next pointers.

Stack

Follows LIFO: Last In, First Out.

Queue

Follows FIFO: First In, First Out.

Supported Operations

  • Insert
  • Delete
  • Search
  • Traversal
  • Memory clearing
  • Unit testing

Time Complexity

StructureInsertDeleteSearchTraversal
Singly Linked ListO(n)O(n)O(n)O(n)
Doubly Linked ListO(n)O(n)O(n)O(n)
StackO(1)O(1)O(n)O(n)
QueueO(1)O(1)O(n)O(n)

Space complexity: O(n) for n stored elements.

Memory Management and Testing

Dynamic nodes are released using delete. Destructors call clear() to avoid memory leaks. The project includes a test suite for basic operations and empty-state behavior.
